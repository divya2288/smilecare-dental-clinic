# 🦷 SmileCare Dental Clinic

A modern and responsive dental clinic website developed as a college web development project. The website provides information about dental services, doctors, treatments, and appointment booking.

## 🌐 Project Overview

SmileCare is designed to provide patients with a simple and user-friendly way to explore dental services and book appointments through an interactive web interface.

## ✨ Features

* 🏠 Modern and responsive home page
* 🦷 Dental services and treatment information
* 👨‍⚕️ Dentist profiles
* 📅 Interactive appointment booking form
* 🔍 Service search and filtering
* 😊 SmileCheck symptom guide
* 🦷 Interactive dental anatomy section
* 📊 Dental health score
* ❓ Frequently Asked Questions (FAQ)
* 📞 Contact section
* 📱 Responsive design for different screen sizes

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Bootstrap 5
* Bootstrap Icons
* Font Awesome
* Google Fonts

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

No backend server is required to run the basic website.

## 📅 Appointment Booking

The website includes an interactive appointment booking form that allows users to enter their appointment details through the website interface.

## 📱 Responsive Design

The website is designed to work across:

* Desktop
* Laptop
* Tablet
* Mobile devices

## 🎓 Project Purpose

This project was developed as part of a college web development project to demonstrate the use of HTML, CSS, JavaScript, and Bootstrap in creating a responsive and interactive website.
